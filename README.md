# Homebench

I'm thinking about building a web-based DIY dashboard for home owners. Users would be able to log in, input their address and - ideally - the dashboard would automatically get their floorplan (know the layout, the number of rooms, and the measurements of those rooms), add home improvement projects to their to do list, and maintain a list of the tools they own. With this information, the dashboard would be able to compute the estimated cost in time and dollars of each project, the estimated increase in value to their home when the project is completed, and new tools they'd need to buy or rent to complete the project. It could also recommend other tools for each project with an estimate of how many labor hours the new tool would save the homeowner and links to where they could buy or rent the tool. I have other ideas and more specific aspects of the idea, but I'll start with this summary to see if you have any questions.
